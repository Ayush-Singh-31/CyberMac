# Changelog

## 0.1.0-dev

### Added

- Native SwiftUI interface with mod imports, library management and diagnostics.
- Queued ZIP imports with individual garment and variant selection.
- redscript compilation, activation and input mapping support.
- Standalone clothing additions with automatic inventory delivery.
- Native body-rig conversion with separate preview and gameplay presets.
- Lethal Curves maximum preset support for first person and motorcycle gameplay.
- Command-line tools for setup, inspection and preparation.

### Improved

- Shared archive tracking to preserve combined clothing and body installations.
- Installation through macOS Installer with backups, verification and restoration.
- Consistent app layout, navigation and import details.

### Fixed

- False installation failures caused by macOS Installer history permissions.
- Recovery of completed installations without reinstalling verified files.
- Body changes appearing in previews while the gameplay rig remained unchanged.
