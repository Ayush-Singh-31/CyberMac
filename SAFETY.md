# Installation and recovery

CyberMac prepares mod files locally, keeps recovery copies and verifies the
result after installation.

## Installation flow

1. CyberMac identifies the package and prepares the selected files.
2. Existing game files are checked and backed up.
3. macOS Installer opens for authorization and installation.
4. CyberMac verifies the installed files before marking the job complete.

Installer scripts are generated by CyberMac for the prepared file plan.
Downloaded package files are treated as mod data. The game must be closed
when installing or restoring files.

## Backups and restoration

Select an import in **Install mods** and choose **Restore previous files** to
return to the preceding files. CyberMac verifies the restored state and retains
the recovery history.

When installations share game archives, restore them in reverse order. This
preserves the sequence of clothing, body and script changes.

Removing an entry from the import list only changes the list. Use the restore
action to undo its installation in the game.

## Local storage

CyberMac keeps its working files under:

```text
~/Library/Application Support/CyberMac
```

This folder contains retained downloads, imported runtimes, generated files,
configuration, installation history, diagnostics and backups. Keep it while you
need the corresponding restore history.

## Troubleshooting

If Installer is cancelled, choose **Retry** on the import. For an installation
error, keep the recovery plan and check the job's details and macOS Installer log.

For setup checks:

```sh
swift run cybermac doctor
swift run cybermac cache-status
```

To capture an issue, open **Advanced → Diagnostics**, start a recording and
reproduce the problem. Add markers for actions such as equipping an item, then
stop recording and choose **Show files**. Recordings remain local and stop after
one hour or 10 GB; CyberMac keeps the latest three sessions.
